Tentang Kasir-Pro V3

Kasir-Pro V3 merupakan aplikasi kasir desktop yang dikembangkan menggunakan Python GUI dan SQLite. Aplikasi ini dirancang untuk membantu pengelolaan produk dan pencatatan transaksi penjualan melalui antarmuka grafis yang mudah digunakan.

Dengan penyimpanan data menggunakan SQLite, aplikasi dapat mengelola informasi produk dan transaksi secara lokal pada komputer pengguna.

Fitur Aplikasi

01. Dashboard

Menampilkan ringkasan aktivitas transaksi dan informasi penjualan melalui halaman utama aplikasi.

02. Manajemen Produk

Membantu pengelolaan data produk yang digunakan dalam aktivitas transaksi penjualan.

03. Transaksi Penjualan

Menyediakan proses pencatatan transaksi, pembayaran, dan perhitungan kembalian.

04. Riwayat Transaksi

Memudahkan pengguna melihat catatan transaksi yang telah dilakukan.

05. Laporan Penjualan

Menyediakan informasi penjualan berdasarkan data transaksi yang tersimpan.

Teknologi yang Digunakan

  • • Python untuk logika aplikasi.
  • • Python GUI untuk antarmuka desktop.
  • • SQLite untuk penyimpanan database lokal.
