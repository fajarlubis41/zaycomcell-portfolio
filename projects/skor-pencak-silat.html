Tentang Proyek

Proyek ini mengeksplorasi konsep aplikasi penilaian pertandingan pencak silat. Juri dapat memberikan input melalui perangkat masing-masing, sementara komputer operator menampilkan informasi skor dalam satu antarmuka.

Node.js, Socket.io, dan JavaScript direncanakan sebagai teknologi untuk mendukung komunikasi data secara real-time. Implementasi dan kesiapan fitur perlu disesuaikan dengan tahap pengembangan proyek.

Fokus Pengembangan

  • • Sinkronisasi input dan tampilan skor.
  • • Komunikasi antarperangkat juri dan operator.
  • • Antarmuka yang mudah dipahami saat pertandingan.
  • • Pengembangan alur penilaian sesuai kebutuhan pengguna.
