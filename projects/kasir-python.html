PYTHON · COMMAND LINE INTERFACE

Tentang Proyek

Aplikasi Kasir Python Berbasis CLI merupakan proyek untuk mempelajari pembuatan aplikasi menggunakan Python. Pengguna berinteraksi dengan program melalui pilihan menu di terminal, tanpa memerlukan antarmuka grafis.

Proyek ini menjadi sarana untuk melatih logika pemrograman, penggunaan fungsi, pengelolaan data, validasi input, serta penyusunan alur program yang terstruktur.

Menu Aplikasi

01. Tambah Produk

Menu untuk memasukkan data produk ke dalam aplikasi.

02. Lihat Produk

Menu untuk melihat daftar produk yang sudah dicatat.

03. Transaksi

Bagian aplikasi untuk mengelola alur transaksi penjualan.

04. Laporan Penjualan

Menu yang ditujukan untuk melihat informasi penjualan sesuai data yang dikelola aplikasi.

Fokus Pembelajaran

  • • Logika program dan navigasi menu.
  • • Pengelolaan data produk.
  • • Pengolahan input pengguna.
  • • Penyusunan alur transaksi.
  • • Pengembangan aplikasi secara bertahap.

Catatan: halaman ini merupakan dokumentasi proyek. Ilustrasi terminal di atas bersifat statis dan bukan aplikasi kasir yang berjalan langsung di browser.
