Cara Download ISO Windows 10 Resmi Tanpa Media Creation Tool

Pernah gak, lagi buru-buru mau install ulang laptop, pas buka situs resmi Microsoft eh malah disodorin Media Creation Tool? Padahal niatnya cuma mau nyimpen file ISO-nya aja buat cadangan atau dipakai nanti pakai Rufus. Bikin gregetan, kan?

Tenang, gak usah pusing. Kita bisa "ngibulin" sedikit sistem Microsoft lewat browser Chrome biar tombol download ISO-nya langsung muncul tanpa aplikasi tambahan. Laptop Windows kamu gak bakal berubah jadi MacBook kok—kita cuma numpang "identitas" browsernya doang.

Sebelum mulai: tampilan situs Microsoft bisa berubah sewaktu-waktu, jadi trik ini belum tentu berhasil di setiap kondisi. Pastikan kamu tetap mengunduh file dari Microsoft, bukan dari situs yang tidak jelas.

1. Meluncur ke TKP (Situs Resmi Microsoft)

Pertama-tama, buka dulu halaman unduhan resmi mereka di Chrome:

Buka halaman ISO Windows 10

Kalau opsi pilihan edisinya udah langsung muncul, kamu boleh langsung loncat ke langkah pemilihan. Tapi kalau yang keluar malah tombol Media Creation Tool doang, lanjut ke langkah berikutnya, ya!

2. Panggil Panel Sakti: Developer Tools

Gak usah panik, kita gak bakal ngoding kok. Cukup tekan tombol F12 di keyboard kamu.

Nanti bakal muncul panel baru (Developer Tools) di sisi kanan atau bawah layar browser. Kalau tombol F12 di laptopmu gak fungsi, tinggal klik ikon titik tiga di pojok kanan atas Chrome, terus pilih More tools → Developer tools. Kalau udah terbuka, klik tab Network.

3. Cari Menu "Network Conditions"

Di dalam panel DevTools tadi, cari lagi ikon titik tiga (posisinya ada di pojok kanan atas panel kecil itu, ya—bukan di browser utamanya).

Arahkan kursor ke More tools, lalu pilih Network conditions.

Panel pengaturannya biasanya muncul di bagian paling bawah panel DevTools. Scroll dikit kalau gak kelihatan, terus cari bagian User agent.

4. Ubah Identitas Browser Jadi Mac

Di bagian User agent, hilangkan centang pada tulisan Use browser default.

Setelah centangnya hilang, buka daftar pilihan di bawahnya dan pilih Firefox — Mac, sama seperti yang terlihat di screenshot.

Sip! Inti triknya ada di sini. Si Chrome bakal pura-pura jadi browser Firefox yang jalan di macOS pas nembak server Microsoft, padahal aslinya kamu tetap pakai Windows biasa.

Tips kecil: Biarkan panel DevTools-nya tetap terbuka selama halaman webnya dimuat ulang supaya pengaturan User-Agent tidak berubah kembali.

5. Refresh Halaman dan Lihat Keajaibannya

Sekarang, balik lagi ke tab halaman download Microsoft tadi, lalu tekan Ctrl + R (atau klik tombol reload di browser). Kalau triknya pas, bagian Select edition bakal langsung nongol dengan pilihan seperti Windows 10 (multi-edition ISO).

6. Pilih Edisi Windows yang Tersedia

Pilih Windows 10 (multi-edition ISO) jika opsi itu muncul, lalu klik Confirm. Tunggu sebentar sampai Microsoft menampilkan langkah berikutnya.

Kalau pilihan ISO tetap tidak muncul, jangan asal mengambil file dari situs lain. Coba muat ulang atau pastikan pengaturannya sudah benar.

7. Tentukan Bahasa dan Arsitektur (32-bit atau 64-bit)

Kalau diminta, pilih bahasa Windows yang kamu inginkan. Berikutnya, Microsoft akan menampilkan tautan unduhan untuk perangkat 64-bit atau 32-bit.

Untuk memeriksa tipe sistem laptopmu, buka Settings → System → About, lalu lihat bagian System type.

8. Unduh dan Simpan File ISO

Klik tautan yang sesuai, lalu simpan file ISO di drive yang ruang kosongnya masih lega. Karena ukurannya mencapai beberapa gigabyte, pastikan koneksi internetmu stabil dan jangan matikan komputer sebelum unduhan selesai, ya!

File ISO ini nantinya bisa dipakai untuk membuat USB installer. Jangan lupa cadangkan isi flashdisk terlebih dahulu karena proses pembuatannya bakal menghapus semua file di dalamnya.

Kalau Misal Triknya Gak Mempan?

  • Pastikan alamat yang dibuka benar-benar domain resmi Microsoft.
  • Pastikan opsi User-Agent tidak kembali ke pengaturan default.
  • Coba muat ulang halaman setelah mengatur ulang User-Agent.
  • Jika cara ini sudah tidak berfungsi akibat pembaruan dari Microsoft, terpaksa gunakan Media Creation Tool resmi mereka.
Info keamanan: Dukungan umum Windows 10 Home dan Pro sudah berakhir pada 14 Oktober 2025. Perangkat yang tidak menerima pembaruan keamanan reguler tentu berisiko lebih besar. Pertimbangkan untuk beralih ke Windows 11 jika perangkat mendukungnya, atau periksa opsi Extended Security Updates (ESU) jika memenuhi syarat.

Pertanyaan yang Sering Ditanyakan

Apakah cara ini mengubah Windows menjadi macOS?

Tidak sama sekali. Yang diubah cuma identitas browser (User-Agent); sistem operasi di komputermu tetap Windows seperti biasa.

Apakah file ISO Windows 10 ini gratis?

File instalasinya bisa diunduh langsung secara gratis dari situs Microsoft, tetapi untuk aktivasi tetap mengikuti ketentuan lisensi resmi masing-masing.

Apakah trik ini bakal selalu berhasil?

Bel tentu. Microsoft sewaktu-waktu bisa mengubah struktur halaman unduhannya. Kalau opsi ISO-nya membandel dan gak muncul, gunakan metode resmi lain yang tersedia.

Apakah bisa langsung install setelah selesai download?

Belum bisa. File ISO ini harus dimasukkan dulu ke media instalasi (seperti flashdisk menggunakan Rufus) sebelum dipakai untuk instal ulang.

Itu dia trik simpel yang bisa kamu coba buat mengakses pilihan ISO Windows 10 langsung dari browser tanpa aplikasi tambahan. Pastikan file bersumber dari Microsoft dan perhatikan juga faktor keamanan sistemmu, ya!
